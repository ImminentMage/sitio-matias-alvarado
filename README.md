# Sitio académico del Dr. José Matías Alvarado Mentado

Este repositorio contiene el sitio web académico del Dr. José Matías Alvarado Mentado, investigador del Departamento de Computación del CINVESTAV.

El sitio reúne su trayectoria, líneas de investigación, publicaciones, estudiantes, colaboradores postdoctorales y eventos de organización científica. Es un sitio estático: no necesita instalación ni base de datos.

## Ver el sitio

Cuando GitHub Pages esté activado, estará disponible en:

`https://imminentmage.github.io/sitio-matias-alvarado/`

También puede abrirse localmente: descarga o clona este repositorio y abre `index.html` en un navegador.

## Estructura

- `index.html`: página principal.
- `curriculum.html`: currículum académico actualizado.
- `temas.html`: líneas de investigación.
- `publicaciones.html`: producción científica.
- Páginas de estudiantes, colaboradores y eventos: formación de recursos humanos y actividad académica.
- `assets/`: logotipo institucional y fotografía autorizada para el sitio.

## Actualización

Para actualizar contenidos, edita los archivos HTML, `styles.css` o los datos de `events.js` y vuelve a publicar los cambios en la rama `main`.

La información académica debe verificarse antes de modificarse. Los enlaces externos pertenecen a sus respectivas instituciones, revistas y perfiles.
